# 2026 无人系统竞赛决赛——27号车

本仓库保存 27 号无人车（JGB520）的完整比赛资料、赛会模型库、初赛工程、历史决赛代码、自建仿真赛道、四超声波避障控制器、Sysplorer 生成代码和一键交接脚本。

> 仓库包含赛会提供的规则、模型与工具，应保持为私有仓库，仅供本队协作和备赛使用。

## 直接入口

- [队员一键交接说明](决赛模型库/Unmanned_Vehicle_Race_2026/Team27_OneClick/README.md)
- [AI 接力说明](AI接力README.md)
- [当前团队模型说明](决赛模型库/Unmanned_Vehicle_Race_2026/TEAM27_README.md)
- [比赛规则 PDF](比赛规则.pdf)

Windows 下进入 `决赛模型库/Unmanned_Vehicle_Race_2026/Team27_OneClick`：

- 双击 `一键运行仿真.bat`：加载依赖、检查模型、运行 90 秒并自动验证首次避障和碰撞计数。
- 双击 `一键生成并上机.bat`：检查实车模型、生成树莓派 C 工程、验证传感器映射并按配置部署。默认安全锁不会启动电机。

## 当前状态

- 车辆：27 号，JGB520。
- 传感器：正前、左前、右前、正后四个超声波；后传感器只监测，不倒车。
- 仿真：90 秒自动测试通过；77 秒进入 `mode=2`，左前障碍约 0.566 m，结束时道路/障碍碰撞计数为 0/0。
- 实车：Sysblock 模型检查、C 代码生成和本机 C 语法预检通过；尚未进行树莓派实机、机械、电气及正式赛道验证。

## 安全提醒

首次上机必须架空驱动轮，逐路遮挡传感器核对通道，确认转向和左右电机方向，并准备人工断电。未经实车标定，不要直接提高速度或缩短停车距离。
