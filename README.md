# 2026 无人系统竞赛决赛——27号车

本仓库保存 27 号 JGB520 阿克曼小车的赛会模型、规则、仿真、纯 MWORKS 控制器和官方外部模式工具。

## 正式参赛入口

- 控制器：`决赛模型库/Unmanned_Vehicle_Race_2026/Controller/ObsAvoidController_Team27_MWorks.mo`
- 实车顶层：`决赛模型库/Unmanned_Vehicle_Race_2026/for_code_JGB520_Team27.mo`
- 烧录说明：`决赛模型库/Unmanned_Vehicle_Race_2026/Team27_OneClick/上车烧录步骤.md`
- 官方工具：`Sysblock 外部模式工具/ExternalMode`
- 规则原文：`比赛规则.pdf`

正式控制算法全部由 MWORKS Sysblock 状态机组成。树莓派 GPIO、串口、电机和舵机 CCaller 沿用赛会接口；避障算法不包含手写 CCaller。控制代码只允许由 MWORKS 生成，并由赛会提供的外部模式工具下载，不允许修改生成后的 C 文件。

## 当前硬件模型（V3 五固定超声）

- `dis1`：车头正前（Front Center）。
- `dis2`：车头右前（Front Right），原顶部扫描探头已机械固定；扫描舵机指令始终为 `0`。
- `dis3`：车身正右（Side Right，约 90°）。
- `dis4`：车身正左（Side Left，约 90°）。
- `dis5`：车头左前（Front Left），由原车尾探头移装。
- 正常巡航速度为 `160 RPM`，接近/开阔转弯保持 `140/130 RPM`，只在近障区降至 `110/100/90/70/60/45 RPM`；急停为 `0`。贴近障碍并且仍有可行侧时，V3.8 以 `45 RPM + 满舵` 优先挪出，保留当前实车上通过率较好的动作。
- 赛道按顺时针运行；左右安全评分接近时仅给予右转 `0.5 cm` 等效偏置，硬安全门控始终优先。
- 正前距离不大于 `26 cm`，或任一前斜向距离不大于 `22 cm`，即提前确认转向方向；正前大于 `30 cm` 且造成转向的前斜向距离大于 `26 cm` 后释放方向锁。
- 左右方向使用瓶颈评分 `min(前斜向距离, 1.6×同侧横向距离)`；前斜向小于 `9 cm` 或同侧横向小于 `8 cm` 时禁止驶入该侧。外围持续无回波按前斜向 `10 cm`、横向 `8 cm` 的保守未知值处理，不再当作 `40 cm` 空地。
- 转向限幅 `±0.58 rad`（仍低于官方机械红线 `±0.6 rad`），每 `0.05 s` 最大变化 `0.16 rad`；锁定避障按三路前向中的最近距离分配 `0.48/0.56/0.58 rad`，避免正前空而前角已近时仍只给小转角。
- 单个左前或右前探头进入 `4.5 cm` 极近区时，先以 `45 RPM` 向另一侧满幅转离；正前原始值进入 `5.5 cm` 极近区时同样处理。若极近读数持续 `0.45 s` 仍未解除，才认定低速满舵自救失败。短暂极近读数以及 `6 cm` 以上的普通连续弯道不会触发这条延迟倒车路径。
- 只有左右前同时不大于 `11 cm`，或正前不大于 `12 cm` 且左右两条阿克曼扫掠路径均不满足门槛时，才允许确认后进入脱困。即使正前射线穿过夹缝显示很远，双前角口袋仍会禁止继续前推。
- V3.8 还会把“已经要求避障、左右扫掠路径都不可行、最近前向不大于 `18 cm`、且不满足平行走廊放行”的静止紧凑状态转成脱困倒车，不再长期保持零速。倒车先回中停车 `0.20 s`，再直退 `0.20 s` 解除顶碰，随后向计划前进空侧的反方向打 `0.38 rad` 中等舵角；倒车为 `-55 RPM`，最短 `0.80 s`、最长 `1.20 s`，最后停车 `0.15 s` 并重新选路。
- 避障后车体与边界平行时，左右90°侧距可能同时小于 `8 cm`。若正前至少 `18 cm` 且左前、右前都至少 `12 cm`，V3.8 将其识别为可通行平行走廊，以 `90 RPM` 继续直行并保留侧向纠偏，不会被新增的紧凑倒车覆盖。
- 软件只能对“至少有一束超声实际看到”的障碍做决策。安装后必须用窄纸板竖边在车头前约 `15～20 cm` 处从左到右连续横扫：全过程应至少有 `dis5/dis1/dis2` 一路进入 `20 cm` 内；若三路同时放空，先把左右前探头向正前收拢并重复测试，不能用状态机猜测真实波束间隙中的障碍。
- 赛场确认不设置斜坡，正式控制器不包含坡道识别和爬坡状态。
