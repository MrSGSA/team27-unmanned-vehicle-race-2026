# Team27 正式 MWORKS 下载步骤

## 1. 安全准备

1. 四个驱动轮全部架空并固定车体。
2. 一人守住总电源，准备立即断电。
3. 首次测试关闭 `Run on boot`，不得直接放到赛道。

## 2. 在 MWORKS 打开正式模型

先完整退出旧的 MWORKS 会话，再打开根目录的 `package.mo`。不要单独打开控制器文件；加载成功后，用户模型树中应出现 `Controller` 子包。然后打开：

- `Controller/ObsAvoidController_Team27_MWorks.mo`
- `for_code_JGB520_Team27.mo`

正式控制器必须能看到 `5-US Continuous` 单状态 Sysblock 图，不能出现避障算法 CCaller。执行模型检查，确认无错误后再执行 MWORKS 代码生成。

若正式顶层中央仍显示红色大叉，说明当前会话仍缓存了旧包结构。关闭 MWORKS 后重新打开 `package.mo`；正常情况下中央组件类型应为 `Controller.ObsAvoidController_Team27_MWorks`，不应显示为普通 `subSystem`。

## 3. 打开赛会外部模式工具

使用仓库 `Sysblock 外部模式工具/ExternalMode`，硬件选择 `Raspberry Pi`。根据工具界面填写：

- Device Address：树莓派 IP。
- Username / Password：树莓派实际账户。
- Build directory：树莓派上的独立目录，例如 `/home/pi/team27_mworks`。
- Build action：首次选择 `Build`，不要选择运行。
- Run on boot：首次必须取消。
- Communication Interface：`TCP/IP`。
- Port：默认配置为 `17725`，若现场配置不同以实际为准。

先完成 `Build`。该过程必须由 MWORKS 外部工具传输并编译，不得手动修改生成后的 C 文件。

## 4. 架空运行

编译通过、车轮仍架空时，才把 Build action 改为 `Build and run`。

按顺序检查：

1. 遮挡确认通道：`dis1前中、dis2右前、dis3正右、dis4正左、dis5左前`。显示名称已改成对应物理位置。
2. 无障碍时速度目标为 `160`，转角为0；原顶部舵机必须始终保持0，不能再往返扫描。
3. 正前保持大于25 cm，单独让左前比右前远至少约4 cm，应产生小幅左转；反向遮挡应产生小幅右转。该连续修正允许轻微平滑“画龙”。
4. 正前约18～19 cm放置软障碍：左前更空应左转，右前更空应右转；近似同分时按顺时针采用右转。20 cm之外不得进入锁定避障。
5. 单独把正左或正右侧距缩短到约3～4 cm，车辆必须立即向相反方向打角；两侧同样近时低速直行，不得左右抖动。
6. 正前有效原始值不大于 `5.5 cm` 应立即停车。控制器不存在负速度和自动倒车；前进极性保持ID1负、ID2正。
7. 转向锁只由正前距离维持：正前恢复到25 cm以上后必须逐渐回正，不允许按固定时间持续打角形成调头。停止外部模式后两电机必须归零。

## 5. 低速落地

架空检查全部通过后，先用2–3 m空旷区域和软障碍物落地测试。当前速度层级为 `160/110/85/65/55/0 RPM`，正前预警/强转/急停为 `20/12/5.5 cm`，正前恢复阈值 `25 cm`，侧向硬排斥 `4.5 cm`，正常连续修正限幅 `±0.24 rad`，避障最终限幅 `±0.55 rad`，每50 ms最大转角变化 `0.12 rad`。任何修改都只能回到正式MWORKS模型重新生成与部署。

## 禁止事项

- 禁止使用生成后的 C 文件作为算法修改入口。
- 禁止使用自制 `team27_main.c`、SSH/SCP 脚本替代正式外部工具下载。
- 禁止首次测试启用开机自启动。
- 禁止未架空车轮直接执行 `Build and run`。

## 已知的新版编译兼容点

原版压缩包在 `rasInit()` 的失败分支中使用了 `int` 返回类型配空 `return;`，新版 2026a 远端 C++ 编译器会因此报 `return-statement with no value`。当前工程只把该失败返回改为 `return 1;`，用于通过新版编译；控制算法、电机换算、串口协议、GPIO 与测距逻辑均未借此修改。该行不是避障算法的一部分，但与原压缩包并非逐字节一致。若赛会要求连这类编译兼容修正也不得存在，应先向技术人员确认官方 2026a 修正版，不能直接恢复后带着已知编译错误上场。
