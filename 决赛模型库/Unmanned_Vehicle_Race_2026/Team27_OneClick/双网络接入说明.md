# Team27 树莓派双网络接入

适用于当前车机的 `dhcpcd + wpa_supplicant` 网络栈和单个 `wlan0` 无线接口。

## 工作方式

- 手机热点存在：树莓派保持客户端模式，通过 `team27-car.local` 访问，电脑保留互联网。
- 手机热点不存在或掉线：连续检测失败约 50 秒后，树莓派切换为 `Team27-Car` 热点，固定地址 `10.27.0.1`。
- 单无线接口不能保证同时承担两个角色，因此这是自动切换，不是同时广播和连接。
- 从回退热点切回手机热点时，开启手机热点后重启树莓派最稳妥。

## 安装

在 Windows PowerShell 中把脚本上传到当前树莓派地址：

```powershell
scp "D:\mworks比赛\team27-unmanned-vehicle-race-2026-main\决赛模型库\Unmanned_Vehicle_Race_2026\Team27_OneClick\scripts\setup_dual_network.sh" pi@10.249.232.244:/home/pi/
ssh pi@10.249.232.244
```

在树莓派 SSH 会话中执行：

```bash
sudo bash /home/pi/setup_dual_network.sh
```

安装过程要求输入车载热点名称和密码，不会把密码写入项目仓库。

## 使用

手机热点模式：

```powershell
ssh pi@team27-car.local
```

车载热点模式：电脑连接 `Team27-Car` 后执行：

```powershell
ssh pi@10.27.0.1
```

强制切换为车载热点：

```bash
sudo team27-ap-mode
```

切回手机热点客户端模式：

```bash
sudo team27-client-mode
```

切换无线模式会中断当前 SSH，这是预期行为。MWORKS ExternalMode 同一时间只能由一名队员执行 `Build and run`。

## 检查

```bash
systemctl status team27-network-fallback --no-pager
systemctl status hostapd dnsmasq --no-pager
journalctl -t team27-network -n 30 --no-pager
```
