# Team27 本地验证入口

## 正式合规边界

本目录脚本只用于本地调用 MWORKS 检查、生成和只读审计，不包含远程上传或自制运行入口。正式比赛下载必须使用赛会提供的 `Sysblock 外部模式工具/ExternalMode`。

首次上车先使用 `Unmanned_Vehicle_Race_2026.Team27_Hardware_Check`，并按 `硬件分级测试.md` 从五路超声开始，禁止直接运行仓库中的高幅值 `CarTest.mo.bak`。

## 本地生成审计

双击 `一键生成并上机.bat` 或运行：

```powershell
& '.\scripts\deploy_realcar.ps1'
```

脚本会：

1. 打开纯 MWORKS 控制器与正式顶层模型；
2. 执行 `CheckModel`；
3. 由 MWORKS 生成 C；
4. 只读核验 V3.9 五固定探头映射、45 RPM低速满舵、平行走廊释放、停车自动恢复、双次带方向倒车、零舵机和有限倒车约束；
5. 拒绝任何 `Team27_ControllerStep` 等手写 C 控制器符号；
6. 编译并运行 35 个生成代码黑盒回归场景。

`tests/run_controller_tests.ps1` 是开发期黑盒测试，只向 MWORKS 生成模型注入传感器序列，不参与烧录。

正式外部工具步骤见 `上车烧录步骤.md`。

## V3 端口语义

五路全部固定，不再扫描：

| 官方通道 | V3实车位置 |
|---|---|
| `dis1` | 前中0° |
| `dis2` | 右前约30°（原顶部舵机超声波） |
| `dis3` | 正右90°（原右前45°） |
| `dis4` | 正左90°（原左前45°） |
| `dis5` | 左前约30°（原尾部） |

控制器每50 ms融合最近五路有效值。正前不大于26 cm或任一前斜向不大于22 cm即提前决策；左右通道按 `min(前斜向, 1.6×同侧横向)` 评分。单个前斜向进入4.5 cm极近区，或正前原始值进入5.5 cm极近区时，优先以45 RPM向安全侧满舵转离；持续0.45 s仍未解除才进入倒车。所有有效测距下只能输出零速的避障状态，在连续停车0.20 s后也会进入恢复倒车。脱困时停车回中0.20 s，先直退0.20 s，再以与计划前进空侧相反的0.38 rad舵角倒车；速度-55 RPM，最短0.80 s、最长1.20 s。同一片未完全解除的障碍最多允许两次倒车，第二次重新评分，近似平局时反选第一次方向；三路前向完全恢复后次数清零。当正前至少18 cm且左右前都至少12 cm时，平行走廊仍以90 RPM继续前进。由于没有后向探头，无效的正前数据只能停车，不能触发盲倒。

实体尖角若恰好落入三路前向超声的真实波束空隙，控制器无法从零观测推断障碍。装车后必须在车头前15～20 cm用窄纸板竖边横扫验证 `dis5/dis1/dis2` 连续覆盖；发现三路同时放空时，应先把左右前探头向正前收拢。
