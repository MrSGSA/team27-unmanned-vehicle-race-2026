# Team27 本地验证入口

## 正式合规边界

本目录脚本只用于本地调用 MWORKS 检查、生成和只读审计，不包含远程上传或自制运行入口。正式比赛下载必须使用赛会提供的 `Sysblock 外部模式工具/ExternalMode`。

首次上车先使用 `Unmanned_Vehicle_Race_2026.Team27_Hardware_Check`，并按 `硬件分级测试.md` 从五路超声开始，禁止直接运行仓库中的高幅值 `CarTest.mo.bak`。

## 本地生成审计

双击 `一键生成并上机.bat` 或运行：

```powershell
& '.\scripts\deploy_realcar.ps1'
```

脚本会：

1. 打开纯 MWORKS 控制器与正式顶层模型；
2. 执行 `CheckModel`；
3. 由 MWORKS 生成 C；
4. 只读核验 V3 五固定探头映射、连续空旷度决策、渐进转向和零舵机/无倒车约束；
5. 拒绝任何 `Team27_ControllerStep` 等手写 C 控制器符号；
6. 编译并运行 19 个生成代码黑盒回归场景。

`tests/run_controller_tests.ps1` 是开发期黑盒测试，只向 MWORKS 生成模型注入传感器序列，不参与烧录。

正式外部工具步骤见 `上车烧录步骤.md`。

## V3 端口语义

五路全部固定，不再扫描：

| 官方通道 | V3实车位置 |
|---|---|
| `dis1` | 前中0° |
| `dis2` | 右前约30°（原顶部舵机超声波） |
| `dis3` | 正右90°（原右前45°） |
| `dis4` | 正左90°（原左前45°） |
| `dis5` | 左前约30°（原尾部） |

控制器每50 ms融合最近五路有效值，前左/前右决定空旷方向，正左/正右只负责车身侧向排斥。扫描舵机命令恒为0，速度命令永不为负。
