# 27号车交接入口（JGB520）

正式参赛文件：

- `Controller/ObsAvoidController_Team27_MWorks.mo`：纯 MWORKS Sysblock 状态机控制器。
- `for_code_JGB520_Team27.mo`：赛会 JGB520 实车接口与 Team27 控制器整合模型。
- `Team27_OneClick/上车烧录步骤.md`：官方外部模式工具操作顺序。

加载时只打开库根目录 `package.mo`。`Controller` 已作为正式子包登记；不要单独加载控制器文件，否则旧会话可能把顶层控制器显示成带红叉的普通 `subSystem`。

本地可执行：

- `Team27_OneClick/一键运行仿真.bat`：旧四传感器虚拟赛道回归，只作为历史仿真基线。
- `Team27_OneClick/一键生成并上机.bat`：现仅允许本地 MWORKS 生成与合规审计，远程上传已硬锁；正式下载必须使用赛会外部模式工具。

当前实车模型采用 `正前 + 右前45° + 左前45° + 正后 + 顶部旋转` 五超声布局；不存在循迹。正式 V2 控制器命令为 `120/90/70`，倒车脱困为 `-50`；正前 `22/10 cm` 分别触发绕障判断/硬停车，原始正前有效值小于 `6 cm` 立即停车，45°原始或滤波值小于 `8 cm` 禁止转入。顶部舵机在 `±0.55` 内以 `0.06/0.05 s` 匀速三角扫描；实车确认正指令朝车辆左侧。方向评分采用扫描/固定 `0.80/0.20`，顺时针同分偏右，固定探头保留硬否决。主动绕障 `±0.52`、最终限幅 `±0.55`，单次锁定最长 `1.4 s`；失败后后方大于 `12 cm` 才允许倒车。本车前进极性为 ID1 负、ID2 正。正式顶层检查、代码生成、只读合规审计和 18 个生成代码黑盒场景均已通过。
